One funny single-line excuse a developer gives when code breaks in production, under 200 characters. A program that writes it to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Developer Excuses" bounty.

The line turns the worn "it worked on my machine" excuse instead of repeating it: the twist reveals what really happened — the developer's own machine holds the `.env` file that was never committed.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
